# Plugin `dog-catalog-kit` — Serveur MCP WoufGuide

Lorsque le serveur MCP `woufguide-catalog` est actif, utilise prioritairement ses outils structurés plutôt que de relire manuellement tout `src/data/breeds.ts` :
- `search_breeds` : filtrer rapidement le catalogue par texte, gabarit, appartement, énergie ou budget.
- `compare_breeds` : obtenir les écarts de scores entre 2 ou 3 races.
- `audit_catalog_gaps` : repérer quels profils de chiens manquent encore au catalogue avant de proposer de nouvelles races.
